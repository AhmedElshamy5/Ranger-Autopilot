# Ranger FC: Hardware-to-Firmware Interface (AS-DESIGNED HARDWARE REFERENCE)

Board: **Ranger FC**, revision **A0.1 placement** (2026-11-11). Schematic A0.1, 142 components, 139 nets, ERC 0/0. PCB: placed, **not routed**.

> The Ranger Flight Controller is currently an unmanufactured, unrouted or partially routed engineering prototype. This document describes the intended electrical design and is not evidence of physical hardware operation.

Start with `ENGINEER_QUICK_REFERENCE.md`.

## Hardware overview
| Item | As designed |
|---|---|
| MCU | STM32H743VIT6, LQFP-100, 3.3 V, internal LDO core supply |
| Clock | 8 MHz HSE crystal. No LSE |
| Sensors fitted | ICM-42688-P (primary IMU), BMP390 (baro). BMI088 second IMU is an optional fit |
| Storage | microSD on SDMMC1 (4-bit) |
| Interfaces | 6 UARTs on connectors/pads + 1 RX-only, FDCAN1, USB FS device, I2C1 external, SPI4 external |
| Outputs | 4 motor (TIM1), 4 servo (TIM4), buzzer, 3 LEDs |
| Power in | 2S–4S battery (6.0–16.8 V) through the ESC connector or solder pads; USB for logic only |
| Rails | 5 V 3 A, 3.3 V 2 A, 3.3 V low-noise sensor rail (switchable), analog 3.3 V |
| Debug | SWD 10-pin, BOOT0 button, test-pad UART |

## Present, optional, external, unverified
- **On the board:** MCU, ICM-42688-P, BMP390, microSD socket, USB-C, CAN transceiver, regulators, buzzer driver, LEDs.
- **Optional fit:** BMI088 (stock risk). The board must work without it.
- **External modules (connector only):** RC receiver, telemetry radio, GPS + compass, companion computer, LiDAR, optical flow, ESC, servos, buzzer.
- **Not on the board:** magnetometer, current sensor, LED-strip output, reset button.
- **Unverified:** everything physical. See `HARDWARE_STATUS.md`.

## Naming note
KiCad's annotation added a trailing `1` to the connector references used in older project documents: `J_USB` is now `J_USB1`, `J_ESC` → `J_ESC1`, and so on. `J1` (battery pads) and `J_S1`–`J_S4` are unchanged.
